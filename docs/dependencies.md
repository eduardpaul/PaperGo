## Native search

The optional [zvec store](search.md#the-store) uses the official v0.7.0 C API SDK and the Go binding's string-array fix from `eduardpaul/zvec-go`. `scripts/native.json` pins the prebuilt SDK archives for Linux amd64/arm64, macOS ARM64 and Windows amd64. PaperGo does not patch or compile zvec sources. Native libraries and notices ship in release archives and the Docker image. The SDK includes compiler runtime libraries under the GCC Runtime Library Exception; their license texts ship alongside the dependency notices.

| Bundled component | License |
| --- | --- |

MIT, Apache-2.0, BSD, ISC, zlib, BSL-1.0 and PostgreSQL licenses are allowed. The GCC Runtime Library Exception permits distributing the SDK's compiler runtimes without applying GPL terms to PaperGo. ONNX Runtime's Eigen dependency includes MPL-2.0 files; its upstream notices and source reference ship with the library.
