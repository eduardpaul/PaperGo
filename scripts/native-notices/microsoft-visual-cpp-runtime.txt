papergo.exe embeds these files of the Microsoft Visual C++ Runtime, which
the embedded ONNX Runtime library requires, and installs them with it in
the data folder's cache/onnxruntime directory:

  vcruntime140.dll  vcruntime140_1.dll  msvcp140.dll  msvcp140_1.dll

They are unmodified copies of the files in Visual Studio 2022's
VC\Redist\MSVC\14.44.35112\x64\Microsoft.VC143.CRT folder, taken from
Microsoft's Visual Studio package Microsoft.VC.14.44.17.14.CRT.Redist.X64.base.
